# Backend پشتیبانی (PHP + MySQL)

این پوشه **کد منبع بک‌اند** است. فایل‌های PHP روی GitHub Pages اجرا نمی‌شوند؛ صفحه‌های فعلی سایت فقط رابط کاربری است و ارسال فرم در نسخه GitHub Pages واتساپ یا برنامه ایمیل را با متن آماده باز می‌کند.

## فایل‌ها
- `schema.sql`: ساخت دیتابیس و جدول درخواست‌ها
- `config.example.php`: نمونه تنظیمات بدون رمز یا کلید واقعی
- `submit-ticket.php`: اعتبارسنجی و ذخیره درخواست با PDO و prepared statements، و اعلان ایمیلی در صورت فعال بودن mail() روی هاست
- `admin.php`: پنل ورود مدیر، مشاهده درخواست‌ها و تغییر وضعیت

## راه‌اندازی روی هاست PHP
1. یک هاست دارای PHP 8.1+ و MySQL تهیه کن.
2. دیتابیس و کاربر دیتابیس را در پنل هاست بساز و فقط دسترسی لازم را بده.
3. فایل `schema.sql` را در phpMyAdmin اجرا کن.
4. پوشه backend را به هاست منتقل کن. بهتر است خارج از پوشه عمومی وب باشد و فقط endpoint لازم از طریق مسیر امن قابل دسترسی شود.
5. `config.example.php` را در سمت سرور به `config.php` کپی کن. مقدارهای DB_HOST، DB_NAME، DB_USER و DB_PASS و ایمیل‌ها را در متغیرهای محیطی هاست قرار بده. رمز واقعی را داخل GitHub قرار نده.
6. برای پنل مدیر، مقدار `ADMIN_PASSWORD_HASH` را با خروجی PHP تابع `password_hash('یک-رمز-قوی', PASSWORD_DEFAULT)` تنظیم کن. خود رمز را در کد یا مخزن ذخیره نکن.
7. مقدار `ALLOWED_ORIGIN` را دقیقاً برابر آدرس سایت منتشرشده تنظیم کن.
8. قبل از عمومی‌کردن فرم، محدودسازی نرخ درخواست در سطح هاست و CAPTCHA اضافه کن و تنظیم ارسال ایمیل هاست را آزمایش کن.
9. پس از تست endpoint روی هاست، آدرس API را به فرانت‌اند متصل کن.

## نکات امنیتی
- فایل واقعی `config.php` را commit نکن.
- حتماً HTTPS فعال باشد.
- پنل admin را با رمز قوی و محدودیت تلاش ورود محافظت کن؛ برای استفاده عملی بهتر است MFA یا دسترسی IP نیز اضافه شود.
- درخواست‌ها شامل اطلاعات شخصی کاربران‌اند؛ فقط به افراد مجاز دسترسی بده و سیاست نگهداری/حذف داده تعریف کن.
- موفقیت ذخیره در دیتابیس به معنی تحویل قطعی ایمیل نیست؛ mail() به تنظیمات میزبان وابسته است.
